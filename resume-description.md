## Short version for a one-page resume

**LifeOS Twin — City Planning Decision-Support Prototype** | Python, FastAPI, SQLite, JavaScript, Three.js  
Built a 3D fictional-city prototype with scenario simulation, what-if comparison, rule-based multi-domain decision support, evidence retrieval and PDF audit reports. Added authenticated workspaces, assumption-based forecasts and validation for imported infrastructure observations. Covered core backend behavior with 120 passing tests.

## Interview-safe explanation

LifeOS Twin is a prototype for exploring planning scenarios in a fictional city. Its traffic, water and electricity values are generated by deterministic Python formulas, not collected from a real municipality. The specialist agents are separate rule-based evaluators, not autonomous LLM agents. Forecasts use growth rates entered by the user. The project can import infrastructure observations and fetch weather context, but imported observations and weather are not currently connected to the simulation engine.

## Claims to avoid

Do not describe this as a production digital twin, a real-time city monitoring platform, a trained predictive AI model, an autonomous multi-agent LLM system, or a validated infrastructure optimization tool. Do not claim real municipal data integration, production deployment, or real-world accuracy.
